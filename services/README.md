# Services Directory

This directory contains modular TypeScript backend services for the Encore backend. Each service should be placed in its own subdirectory (e.g., `ocr/`, `validation/`, `storage/`) and follow project conventions for separation of concerns and named exports.

**All backend service code must reside in `backend/services` and its subdirectories. Never create or use a top-level `services` directory.**
